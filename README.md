# ToolBox

Production-oriented all-in-one document, image, conversion, developer and utility platform.

## Initial product direction

- PDF tools
- Image tools
- Document conversion
- Hash and security tools
- Developer utilities
- Everyday calculators

## Development principle

Start with browser-first processing wherever practical. Add server-side workers only for operations that genuinely require them.

## Current milestone

Milestone 001: foundation and application shell.

Next milestone: reusable Tool Engine + JPG/PNG to PDF.
